FitMind – AI-Powered Fitness Knowledge Assistant

FitMind is an AI-powered fitness knowledge assistant built using Retrieval-Augmented Generation (RAG). It allows users to ask fitness-related questions and receive context-aware answers based on a curated collection of fitness knowledge documents.

Instead of relying entirely on the language model's pre-trained knowledge, FitMind retrieves relevant information from a vector database and uses it as context to generate more relevant and grounded responses.

🚀 Features

AI-Powered Conversations: Ask fitness-related questions in natural language.

Retrieval-Augmented Generation (RAG): Retrieves relevant information from a custom fitness knowledge base before generating answers.

Semantic Search: Finds relevant content based on the meaning of a question rather than just keyword matching.

Vector Database: Uses Qdrant to store and retrieve document embeddings.

Document Processing: Converts PDF documents into smaller chunks for efficient retrieval.

Source-Based Responses: Uses retrieved documents as context when generating answers.
